--------------------필수 프로그램 설치----------------
1. Node.js 설치

LTS (Long-Term Support) 버전 다운로드
(현재는 “Recommended for most users”로 표시된 버전 선택)

"Add to PATH" 꼭 체크

설치 완료 후 명령 프롬프트(CMD) 또는 PowerShell 열고 확인:

node -v
npm -v

두 버전이 표시되면 성공


2. MySQL 8.0 설치

“MySQL Installer for Windows (Community)” 다운로드

설치 중에 “Server + Workbench” 선택

root 계정 비밀번호 설정 - 기억해두기

설치 완료 후 서비스 실행 확인:

net start MySQL80

→ “서비스가 성공적으로 시작되었습니다.” 뜨면 OK
---------------MySQL 데이터베이스 생성 및 테이블 불러오기----------------

1. MySQL 서버 실행 확인

CMD(또는 PowerShell)에서 아래 명령어 입력:

net start MySQL80 또는 net start MySQL


“서비스가 이미 시작되었습니다.” 라면 그대로 진행

2. MySQL 접속

create_db.sql이 있는 폴더로 이동하여

mysql -u root -p

비밀번호 입력 → mysql> 프롬프트가 뜨면 접속 성공.

3. SQL 파일 실행 < db 폴더 내부에 create_db있음
source create_db.sql;

다른경로에 있다면 경로\create_db.sql;

정상 생성 확인

SHOW TABLES;

테이블 이름들이 뜨면 완료
 
2-1. vscode를 사용한다면 마켓플레이스에서 MySQL 확장 다운을 받고 좌측에 생긴 데이터베이스칸으로 이동

비밀번호 입력하여 연결 후 쿼리문 순차실행

테이블란에 column 추가되었으면 완료


이제 2개 서버를 돌릴 2개의 터미널이 필요하고 powershell보단 cmd 환경을 추천 잘 안되면 관리자권한 실행


-------------------------------백엔드(Node.js) 설정------------------------------------------- 터미널 1개 필요


1. 의존성 설치 (최초 1회)
\backend 폴더로 이동하여
npm install

2. 환경변수 파일 확인 (backend/.env)

비밀번호를 자신의 sql비밀번호로 교체

같은 폴더 내부의 db.js의 비밀번호도 교체

3. 서버 실행 (매번)
npm run dev


정상이라면 콘솔에 예시처럼 뜸:

Connected to MySQL database
Server running on port 3000

4. 간단 동작 확인 (선택)

브라우저에서 http://localhost:3000 확인.


-------------------------------FastAPI 서버(크롤러) 준비 & 실행---------------------------------------- js로 크롤링이 가능하게 되어 제외 


-------------------------------프론트엔드 실행---------------------------------------- 터미널 1개 필요

1. replz폴더에서 의존성 설치(최초 1회)
npm install

2.개발 서버 실행 (매번)
npm run dev

3. 접속

브라우저에서 표시된 로컬 주소로 접속
(일반적으로) http://localhost:5173

참고: 백엔드가 3000에서 정상 동작 중이어야 프론트의 API 연동이 됩니다.
